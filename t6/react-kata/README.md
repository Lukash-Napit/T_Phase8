# Blog CMS Dashboard

A responsive, data-driven React dashboard.

## Setup Instructions
1. Run `npm install`
2. Run `npm run dev`
3. Open `http://localhost:5173`

## Features
- Data simulated via mock API (`src/mockData.js`)
- Responsive CSS Grid layout (stacks on mobile, expands on desktop)
- Interactive Bar Chart (Comments by author) and Line Chart (Posts over time)
- Fully accessible: Text alternatives provided for charts via `<details>` tags.
- Filterable & Sortable Data Table with Pagination.
- Semantic HTML structure (real `<table>`, `<label>` associations).
