# Accessible Component Library (Assignment A8)

A collection of fully accessible, keyboard-operable React components.

## Setup

1. `npm install`
2. `npm run dev`
3. Open `http://localhost:5173`

## Components Included
- **Button**: Native `<button>`, variants, disabled state, focus-visible ring.
- **Modal**: Focus-trapped, Escape to close, returns focus to trigger.
- **TextInput / Select / Checkbox**: Programmatic labels, `aria-invalid`, `aria-describedby` for errors.

## Verification
Run Lighthouse in Chrome DevTools against the local URL to verify the Accessibility score.
